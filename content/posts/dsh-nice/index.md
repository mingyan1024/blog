## 1、安装、启动deepseek

```
npx @deepseek-ai/dsh web 
```

## 2、安装、卸载插件

```
安装（add 后面是插件名称）
npx -y @deepseek-ai/dsh plugin --profile web add  dsh-web-plugin-manager
```

```
卸载（remove 后面是插件名称）
npx -y @deepseek-ai/dsh plugin --profile web remove  dsh-web-plugin-manager
```
